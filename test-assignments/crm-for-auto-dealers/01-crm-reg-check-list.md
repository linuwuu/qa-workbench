## CRM REGISTRATION FORM CHECK-LIST
Допускаю, что правила регистрации такие: Сотрудник приходит по приглашению и попадает к своему дилеру. 
Если поведение зависит от правил продукта, пишу рядом «по требованиям».

Открытие формы
[ ] Ссылка из письма открывает форму
[ ] Email и дилер уже подставлены из приглашения (точно сказать не могу, нужна документация) 
[ ] Истёкшая ссылка: понятное сообщение, формы нет
[ ] Использованная ссылка: «Ссылка уже использована»
[ ] Ссылка, которую админ отозвал, не работает
[ ] Поменял в токене одну букву -> отказ
[ ] Открыл по http:// -> перекинуло на https://

Email
[ ] Обычный валидный адрес принимается
[ ] Без @, без домена, с пробелом внутри -> ошибка
[ ] Уже занятый адрес -> ошибка, fict-person@mail.ru при занятом Fict-Person@mail.ru сообщает о том, что такой Email уже существует в системе
[ ] Пробелы по краям обрезаются
[ ] Адрес с + (name+crm@mail.ru) принимается (или нет, по требованиям)
[ ] Кириллический домен (почта.рф) - по требованиям, но форма не падает
[ ] Длина на границе: 254 символа проходит, 255 нет (или другое число из требований)
[ ] Пустое поле -> ошибка

Пароль
[ ] Длина: min−1 не проходит, min проходит, max проходит, max+1 не проходит
[ ] Нет цифры, буквы или спецсимвола - ошибка по политике
[ ] 12345678, qwerty123 и прочая классика из топа слабых - отказ (или другое, по требованиям)
[ ] Кириллица и пробелы в пароле - по требованиям, главное, чтобы потом с ним можно было войти
[ ] Символы скрыты точками. Кнопка «показать» показывает и прячет, введённое не теряется
[ ] Требования к паролю видны до ввода, или после 1 попытки.

Подтверждение пароля (если есть)
[ ] Если не совпадает -> ошибка, форма не уходит

Имя
[ ] Кириллица, латиница, дефис, апостроф, буква ё - проходят
[ ] Одни пробелы -> ошибка
[ ] 255 символов: обрезается или ошибка, вёрстка цела
[ ] Цифры и эмодзи - по требованиям, но ничего не падает
[ ] <script>alert(1)</script> сохраняется как текст. При просмотре данных этого пользователя в панели администратора код должен отображаться исключительно как обычный текст, а не исполняться браузером.

Номер телефона
[ ] +7 999 123-45-67, 89991234567, +7 (999) 123 45 67 - всё сводится к одному виду
[ ] Буквы, лишние или недостающие цифры -> ошибка


Согласие на обработку ПДн
[ ] Без галочки форма не отправляется
[ ] Ссылка на политику открывается и ведёт на актуальный текст
[ ] В базе сохранился сам факт согласия и дата

Кнопка и отправка
[ ] Кнопка неактивна, пока форма не готова (если так задумано)
[ ] Enter отправляет форму 
[ ] Двойной клик = один аккаунт и одно письмо
[ ] Во время запроса видно, что идёт загрузка, кнопка заблокирована
[ ] После отправки нажал «Назад» и обновил страницу -> дубля нет
[ ] Выключил сеть посреди отправки -> понятная ошибка, полусозданного аккаунта нет

Ошибки на форме
[ ] Ошибка стоит у того поля, где проблема, и написана понятным языком
[ ] Видны все ошибки сразу, а не по одной за отправку (по требованиям)
[ ] После ошибки введённые данные на месте, кроме пароля - тут по требованиям
[ ] Тексты ошибок фронта и сервера совпадают

Письмо подтверждения
[ ] Приходит за минуту-две
[ ] Ссылка ведёт на корректный домен по HTTPS
[ ] В письме нет пароля
[ ] Ссылка срабатывает один раз

[ ] Имя с HTML-тегами не ломает письмо и не превращается в ссылку
[ ] Письмо не падает в спам (SPF, DKIM) и нормально выглядит в Gmail, Яндексе, Outlook

[ ] До активации в CRM не пускает, видна только страница ожидания
