## Тест-кейсы

Один позитивный (основной сценарий работает) и один негативный (система не даёт создать дубль)

### PC-01. Успешная регистрация сотрудника по приглашению

| Поле | Значение |
| --- | --- |
| Приоритет | P0  |
| Тип | Позитивный, функциональный |
| Предусловия | Админ дилера отправил приглашение на `anya-nyan@mail.ru` с ролью «Менеджер». Email в системе не зарегистрирован |
| Тестовые данные | Имя: Аня Нян · Телефон: +7 999 123-45-67 · Пароль: `the_strong_password123` |

| Шаг | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1 | Открыть ссылку из письма-приглашения | Открыта форма регистрации, email подставлен, название дилера указано |
| 2 | Заполнить Имя, Телефон, Пароль, Подтверждение пароля | Ошибок валидации нет |
| 3 | Отметить согласие на обработку ПДн | Кнопка «Зарегистрироваться» стала активной |
| 4 | Нажать «Зарегистрироваться» | Сообщение «Проверьте почту». В БД есть запись со статусом «Не подтверждён» |
| 5 | Открыть письмо подтверждения, перейти по ссылке | Аккаунт активирован, открыта страница входа |
| 6 | Войти с `anya-nyan@mail.ru` и паролем из шага 2 | Открыта CRM дилера, роль «Менеджер», раздела «Администрирование» нет |

Постусловие: повторный переход по ссылке-приглашению даёт «Ссылка уже использована». Тестовый аккаунт удалить после прогона.

### NC-01. Регистрация с уже занятым email в другом регистре

| Поле | Значение |
| --- | --- |
| Приоритет | P0 |
| Тип | Негативный, функциональный |
| Предусловия | В системе есть активный аккаунт `top-dealer@mail.ru`. Есть новая действующая ссылка-приглашение |
| Тестовые данные | Email: `Top-Dealer@Mail.ru` · Имя: Иван Воздуханов · Пароль: `the_strongest_password321` |

| Шаг | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1 | Открыть ссылку-приглашение | Открыта форма регистрации |
| 2 | Ввести email `Top-Dealer@Mail.ru`, заполнить остальные поля, отметить согласие | Поля приняты |
| 3 | Нажать «Зарегистрироваться» | Ошибка у поля Email: «Пользователь с таким email уже зарегистрирован». API вернул 409 |
| 4 | Проверить таблицу users и список сотрудников у админа | Одна запись с этим email, новой нет. Письмо не отправлено |

Постусловие: существующий аккаунт не изменён, вход со старым паролем работает.
